The folder letters contain the speach sound used as targets
The folder digits contain the speach sound used as primes

Each folder in data contains one file per participant. Each line corresponds to one trial, the columns correspond to the following variables:

- col_0 = participant initials
- col_1 = participant numerical identifier 
- col_2 = trial number 
- col_3 = prime congruency ("cong": visual and auditory primes are identical / incong: visual and auditory primes are different) 
- col_4 = relation between prime and target congruency ("rel" : both primes and targets are identical/different ; "unrel": primes are identical/different & targets are different/identical)
- col_5 = whether the auditory prime is unmasked (1) or masked (0)  
- col_6 = whether the visual prime is unmasked (1) or masked (0)  
- col_7 = auditory prime stimulus (2 / 4 / 6 / 8) 
- col_8 = auditory target stimulus (b / j / k / m)
- col_9 = visual prime stimulus (2 / 4 / 6 / 8) 
- col_10 = visual target stimulus (b / j / k / m)
- col_11 = response on the target (1: congruent / 0: incongruent) 
- col_12 = reaction time on the target in milliseconds 
- col_13 = response on the prime (1: congruent / 0: incongruent) 
- col_14 = reaction time on the target in milliseconds
